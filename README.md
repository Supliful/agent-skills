# Supliful agent skills

Skills that teach coding agents (Claude Code, Cursor, Codex and others) to build
on the [Supliful API](https://developers.supliful.com).

## Install

```bash
npx skills add supliful/agent-skills
```

## Skills

| Skill | What it does |
|---|---|
| `supliful-api` | Products, orders and webhooks: auth, the order lifecycle, signature verification, errors and retries |
